# Official shadcn Avatar docs portraits

Vendored from the Avatar catalog demo at https://ui.shadcn.com/docs/components/avatar
(`https://github.com/shadcn.png`, `https://github.com/leerob.png`,
`https://github.com/evilrabbit.png`).

These are the catalog faces, not invented reviewer photos. `public.reviews`
has no photo column. SITE-109 uses them so AvatarImage has a real `src` and
the group is portraits, not letter discs. `shadcn.jpg` is the GitHub avatar
bytes (JPEG) served under that name.
