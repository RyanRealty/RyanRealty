How to use this

Review checklist

  1. Click each card to open the full mockup in a new tab.
  2. Scan top-to-bottom. is the section structure right for that route?
  3. Mark anything to redirect. too much content, wrong order, missing block, wrong data source.
  4. If all 14 look right, I run the /goal and start Wave 3 / route 2 (listing detail), per docs/EXECUTION_PLAN.md.
  5. If you want to iterate on any mockup via the Claude Design tool, send me back a new bundle and I'll apply the patch via codebase-patches/APPLY.md.
