# Print / CMA charts

A printed page cannot hover, scrub, or replay. The HTML skill's hover layer
does not apply. Everything a tooltip would have said must sit on the graphic
or in a table under it.

## Rules that replace hover

- Direct-label the one or two marks the sentence is about.
- A table twin is legal and often better (two units, 12 months of counts).
- `aria-label` on the SVG is the caption, not a hiding place for the numbers.
- Source line under the drawing, named grain, window, n. CLAUDE.md §0.

## Type

- H2: Amboqia (the claim).
- Body / caption / source: Geist.
- Figures, axis ticks, table cells: Geist, `font-variant-numeric: tabular-nums`
  only in the table or on ticks.
- Never Amboqia on a chart number.

## Marks on cream

Navy `#102742` on cream `#faf8f4`. Stems 1.1–1.6px. Lines 1.5–2px. Circles
r=3 hollow for context, filled for the subject. Axes 0.75px
`rgba(16,39,66,0.22)`.
