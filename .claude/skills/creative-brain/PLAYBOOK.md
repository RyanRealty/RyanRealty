# PLAYBOOK — the application instrument

This is how the brain gets APPLIED, not just known. Every piece runs these checks at each stage. A check is pass/fail; a failed check either gets fixed or the piece dies there. Each check cites its volume. Fill out [templates/piece-brief.md](templates/piece-brief.md) as you go — no piece enters production without a completed brief.

## Stage 0 — FEEL (before anything)

- [ ] ONE target emotion chosen from the feel-good palette (awe / chills / being-moved / satisfying / delight / humor) — not two, not "positive vibes" *(emotion-mechanics)*
- [ ] The trigger mechanism for that emotion is named, and the piece's payoff moment implements its recipe literally (e.g. being-moved = a bond visibly and SUDDENLY deepens) *(emotion-mechanics)*
- [ ] The emotion is high-arousal (awe, delight, moved) if reach is the goal — calm doesn't travel *(emotion-mechanics: Berger & Milkman)*
- [ ] Know / feel / do written in one line each; FEEL outranks *(studio-pipeline: Giant Ant)*

## Stage 1 — IDEA + CONSTRAINT

- [ ] The idea survives one sentence (say it aloud; if it needs a second sentence, it isn't an idea yet) *(studio-pipeline: Clair)*
- [ ] A hard formal constraint is chosen BEFORE the story, and the constraint is generative (it writes the piece: one line, one shot, one material, two colors) *(masters: law 1)*
- [ ] The trope test: is this the first thing a model would produce for this kind of idea? If yes, dead *(LESSONS #1)*
- [ ] The filmable test: could a camera capture this? Then license/shoot instead *(four laws)*
- [ ] The hang test: would it survive an Annecy shorts block, or only a feed?

## Stage 2 — LINEAGE

- [ ] Named non-AI artistic lineage (specific artists/films, not vibes) — this anchors the grade and breaks the model's default aesthetic *(ai-filmmakers: Trillo)*
- [ ] Taste sources checked are festivals/art history, never "AI video trends" *(LESSONS #9)*

## Stage 3 — SOUND SPINE

- [ ] Temporal skeleton locked with sound FIRST — a track, a VO, a rhythm map with bpm, or designed silence *(masters: Schwizgebel, McLaren)*
- [ ] The sound is human/authored, not generated filler — sound carries the piece *(ai-filmmakers: rule 5)*
- [ ] Melody, not rhythmic bed, if music (melody is the fame-driving feature) *(marketing-psychology: Listen Up!)*

## Stage 4 — STYLE FRAME (authored, iterated, gallery-grade)

- [ ] Frame 1 authored by us (code / SVG / composite / owned assets) — the model only moves what we made
- [ ] Fluency audit: a stranger parses the frame in under a second — one subject, high figure-ground contrast, sharp focus *(neuroaesthetics #1)*
- [ ] Colors are colors OF liked things (sky, water, sunlit wood, greenery; our navy/cream) — brightness set for pleasantness, saturation set for the arousal level the emotion needs *(neuroaesthetics #7-8)*
- [ ] If landscape: prospect-refuge framing (vista through sheltering foreground); water featured if available *(neuroaesthetics #9)*
- [ ] Dominant lines curved unless tension is wanted *(neuroaesthetics #4)*
- [ ] Grade peak-shifted past neutral (the heightened version reads as more real) *(neuroaesthetics #3)*
- [ ] ZERO typography or exact numbers in any frame a model will touch *(LESSONS #3)*
- [ ] The still was iterated until it would hang — a weak drawing animated is a weak film *(LESSONS #7)*

## Stage 5 — TIMED BOARD

- [ ] Seconds written on every beat (e-konte discipline) *(masters: Ghibli)*
- [ ] Ma scheduled — at least one breathing beat that advances nothing but lets tension build *(masters: Miyazaki)*
- [ ] The anticipation curve drawn: earliest promise cue placed as early as possible; ONE clean peak; resolution lands on a NEW element entering (sound + image within ~2 frames) *(emotion-mechanics: Schultz, Salimpoor)*
- [ ] A gap opened early (question/incompleteness) that the final beat snaps shut; for loops, the close re-opens it *(emotion-mechanics: Loewenstein, Zeigarnik)*

## Stage 6 — MOTION TEST

- [ ] Riskiest movement proven cheapest-first (one clip, one code render, one crop-pan mock) *(studio-pipeline: Buck/Gondry)*
- [ ] For formal-constraint pieces: code animation considered first (exact control, zero drift) *(LESSONS #6)*

## Stage 7 — PRODUCTION

- [ ] Overgeneration budgeted: multiple takes per shot, multiple models as multiple takes; expected keep-rate ≤ 25% *(ai-filmmakers: rule 2)*
- [ ] Prompts avoid trope-adjacent words; describe the phenomenon, not the technique *(LESSONS #1-2)*
- [ ] Style-drifts logged in the brief — gifts kept, constraint-breaks killed *(LESSONS #4)*

## Stage 8 — EDIT

- [ ] Cut to the sound spine, word-by-word / beat-by-beat *(ai-filmmakers: Trillo)*
- [ ] The model's 3-second rhythm resisted — long takes earned where the piece wants them *(ai-filmmakers: rule 10)*

## Stage 9 — POST

- [ ] Unified grade + added grain/texture across all shots — disparate generations become one film *(ai-filmmakers: rule 4)*
- [ ] Type and numbers composited in post; any public number carries a §0 verification trace
- [ ] Default AI sheen broken on purpose (period grade, texture, authored imperfection) *(ai-filmmakers: rule 8)*

## Stage 10 — JUDGE, SCREEN, LEDGER

- [ ] Kill tests re-run on the finished cut (one-sentence, hang, trope, broken-detail)
- [ ] The broken-detail test: one incoherent detail snaps transportation — glitches are either authored subjects or gone *(emotion-mechanics: Green & Brock)*
- [ ] Distinctive-asset audit: is it unmistakably ours without a logo slap (world, palette, character, melody)? Logo as closer only *(marketing-psychology: Ehrenberg-Bass)*
- [ ] Screening-room contact sheet with honest verdicts and rankings; Matt sees only defended work; nothing publishes without explicit approval
- [ ] LESSONS.md appended — a session that learned and didn't write it down has failed

## Brand-growth frame (why we're doing this at all)

- We are entertaining the ~95% not in market so we're the name in memory when they enter it *(marketing-psychology: 95:5)*
- Judged on fame and feeling over years, never lead-attribution windows *(Binet & Field)*
- Right-brain features checklist on every piece: character with agency, sense of place, unfolding story, implicit meaning, melody *(Orlando Wood's Lemon)*
- Consistency compounds: same palette, same world, same character, same sonic identity, for years *(mere exposure/fluency)*
