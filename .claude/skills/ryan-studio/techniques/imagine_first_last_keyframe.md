# Imagine first/last frame plate

Source: video-skills-research #3, round2 playbook (@imagine 2026-09-08, @XFreeze 2026-09-23)

## Recipe
Set image roles: First = approved still A, Last = still B (same framing). Prompt: `Static locked-off wide shot; seasons change smoothly from summer to winter; snow gradually covers the ground; camera does not move.` Chain clips >15 s from the last frame.

## Use
List `imagine_first_last_keyframe` in brief.techniques. Mandatory spec_rules still apply.
