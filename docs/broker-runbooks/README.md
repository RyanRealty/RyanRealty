## The shared workflow in one sentence

A lead arrives in FUB on its own, you read the card and send one manual SMS from a template, you change the stage from Lead to A - Hot 1-3 Months, the action plan does the rest.

## Why each broker has their own page

- **Matt** owns architecture, sees full pipeline, runs weekly review, gets the weekly digest.
- **Paul and Rebecca** work assigned leads, get the daily digest, use their own attribution URL for inbound campaigns.

The shared mechanics (SMS template, stage change as trigger, plan cadence, pause-on-reply) are identical across all three.
