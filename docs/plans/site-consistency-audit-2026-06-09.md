### P0.1 — /pulse feed order built from localStorage + Math.random inside a useMemo during render -> #418 hydration abort kills the whole client tree
- **File:** `components/pulse/PulseFeed.tsx:272`  ·  **dim:**   ·  **gated:** false

### 1. `ci:poison-null` — covers 17
- **Rule:** FAIL any function under lib/data/**/*.ts that is wrapped in unstable_cache OR makeResilientCached AND, in a branch that tests a Supabase result's `error` (or that destructures only `{ data }` thereby dropping `error`), returns an empty/degraded value (return []/null/{}/EMPTY-sentinel, or `?? []` log-and-continue, or catch{return null}) instead of throwing. The only sanctioned non-throwing escape is makeResilientCached(...,<fallback>) from lib/data/cache/resilient.ts. PASS when every cached reader throws on a Supabase error (so unstable_cache never stores the rejected/empty result) and returns the empty fallback only on a genuine empty success.
- **Rationale:** This is the single highest-leverage systemic class: a transient pooler/timeout blip caches an empty result for 5min-24h, silently degrading the exact heroes, market bands, video heroes, reviews and open-house grids that ads land on.
