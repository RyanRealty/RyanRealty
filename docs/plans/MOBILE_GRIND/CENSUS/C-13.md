# C-13 · Number formatting divergence

`components/site/kb/KbListingMapImpl.tsx:42` carried its own money formatter:

```js
v >= 1e6 ? `$${(v/1e6).toFixed(1)}M` : `$${Math.round(v/1000)}K`
```

So a map popup read **$2.2M** while the featured tiles on the SAME page read **$3,200,000**. VOICE.md
Mechanics: "Currency to the nearest thousand: `$895,000`."

**census_count = 1 · fixed_count = 1** — `money()` now delegates to `kbMoneyFull`, the canon formatter
already used by every sibling surface. One implementation, not a second.
