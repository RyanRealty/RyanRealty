# C-20 · Arbitrary subset where the full set is the point (+ C-10 · Silent drop)

## The three stacked filters

`app/communities/[slug]/page.tsx:537-556` turned a 19-entry registry into six or fewer:

1. `cityResorts(citySlug)` — same city only. On Tetherow that dropped Eagle Crest, Black Butte Ranch,
   Brasada Ranch, all three Sunriver communities and Crooked River Ranch — seven of the most
   recognizable names in Central Oregon.
2. `.slice(0, 6)`.
3. `if (!img) return null` — **silent**. A community vanished because an asset was missing, invisibly.

**census_count: 1 builder, 13 communities suppressed on the Tetherow page · fixed_count: 13**

## Fix — order by relevance, never filter by it

`allCommunities()` from `resolveGeoScope` (C-18), sorted same-city-first then alphabetically, excluding
only the community whose page it is. Nothing is hidden; the most relevant is still first.

The `if (!img) return null` is replaced by the labeled `cityHero(city_slug)` fallback — the pattern
`/communities` already uses. **That closes C-10 in the same change**, because it was the same line.

`town` now reads `r.city` rather than the current page's city: a Sunriver community shown on a Bend
page is in Sunriver, and labelling it "Bend" was wrong the moment the city filter came off.

## Which communities the silent drop was hiding

Exactly the four `ci:gates` already warns about for missing `RESORT_IMG`:
**Mt Bachelor Village · Inn of the 7th Mountain · Rivers Edge · Mountain High** — and, per the C-18
coverage report, the same four that have no boundary polygon. The thinnest registry entries were being
silently erased from the one surface meant to help people discover them.
