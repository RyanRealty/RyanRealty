# C-07 · Naked-verb / placeholder headings

Census: every component default for `title` / `heading` / `eyebrow` across `components/site/**`, plus
every caller, flagging any default that renders meaningful-looking but contentless text.

| component | default | callers passing a real value | verdict |
|---|---|---|---|
| `KbExploreTowns` | `title = 'Explore'`, `eyebrow = 'Explore'` | 3 of 4 (`area-guides` ×2, `housing-market`) | **DEFECT → FIXED** |
| `KbFeatured` | `eyebrow = 'Featured homes'` | — | fine: states what the section is |
| `KbListingMapImpl` | `title = 'Every home\nfor sale'` | — | fine |
| `KbMarketHud` | `eyebrow = 'The market'` | — | fine |
| `KbHero` | `eyebrow = 'Central Oregon Real Estate'` | — | fine |

**census_count = 1 · fixed_count = 1**

## What happened

The homepage was the only `KbExploreTowns` caller omitting `title`, so it silently inherited the
placeholder and rendered **"EXPLORE"** as its H2. A design audit noticed the section read as filler and
gave the *eyebrow* scent copy ("The six towns") to compensate — fixing the symptom one line above the
cause.

VOICE.md, Site pages: "Headings are sentence case and say something specific." Search-traffic rule 2:
"Headings state what someone would search." Nobody types "explore".

## Fix

1. Homepage passes `title={'Where people\nare buying'}`, eyebrow `Central Oregon`.
2. **`title` and `eyebrow` are now REQUIRED** — the placeholder defaults are deleted, so no future
   caller can inherit one.
3. "The six towns" dropped: `TOWN_ORDER` is six slugs, but `lib/city-content.ts` carries Prineville and
   Madras too, so it read as a claim about the region and undersold the coverage.

## Gate — G62 `ci:naked-verb-headings`

Literal equality against a closed list of bare verbs, checked on heading tags **and** on
`title=` / `heading=` values — including the **default-parameter form `title = 'Explore'`**.

**The first cut of this gate failed its own proof.** Its regex required `title="..."` with no spaces
around `=`, so reintroducing `title = 'Explore'` passed clean — it would have gated everything except
the mechanism that actually shipped the bug. Corrected to allow whitespace, then re-proven:
defect → exit 1 naming `KbExploreTowns.client.tsx:18`; restored → exit 0.
