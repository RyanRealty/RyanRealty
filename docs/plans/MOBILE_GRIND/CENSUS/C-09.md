# C-09 · Component discards the caller's intent

Census 2026-08-06. Method: find shared components whose render branches replace a prop the caller
passed with a hardcoded literal.

## The defect

`components/site/kb/KbFeatured.client.tsx:177-180`

```jsx
{totalCount != null && totalCount > shown.length
  ? `See all ${totalCount.toLocaleString('en-US')} homes for sale`   // caller's label DISCARDED
  : viewAllLabel}
```

The rail shows at most 12 tiles, so on any geography page with more than 12 active listings the
condition is always true and the caller's `viewAllLabel` is never rendered. Six pages were passing a
correctly scoped, place-named label and getting a placeless string instead.

**KbFeatured is mounted on 18 pages — every one of them was affected.**

## Callers passing a place-scoped label that was being thrown away

| file:line | label passed | rendered before |
|---|---|---|
| `app/communities/[slug]/page.tsx:782` | `See every {community.name} home for sale` | `See all 38 homes for sale` |
| `app/cities/[slug]/page.tsx:476` | `See every {cityName} home for sale` | `See all 496 homes for sale` |
| `app/cities/[slug]/[neighborhoodSlug]/page.tsx:429` | `See every {neighborhood.name} home for sale` | placeless |
| `app/subdivisions/[slug]/page.tsx:495` | `See every {displayName} home for sale` | placeless |
| `app/zip/[zip]/page.tsx:410` | `See every {cityName} home for sale` | placeless |
| `app/areas/[slug]/page.tsx:273` | `Browse every Central Oregon home for sale` | placeless |

**census_count = 6 · fixed_count = 6**

## Fix

Added a typed `viewAllPlace?: string` prop and composed both signals instead of choosing one:

```jsx
`See all ${totalCount.toLocaleString('en-US')} ${viewAllPlace ? `${viewAllPlace} ` : ''}homes for sale`
```

Rejected: string surgery on `viewAllLabel` (regex-replacing "See every" with "See all N"). It is
fragile, silently wrong for any caller phrasing it differently, and unreadable. An explicit prop is
typed, obvious at the call site, and impossible to get half-right.

`viewAllLabel` is retained as the no-count fallback — it still renders when `totalCount` is null or
does not exceed the tiles shown, which is the case the original prop was written for.

Matt's reported instance read "SEE ALL 38 HOMES FOR SALE" — the count matches, the place is now present.

## Gate

Not gated. The decidable form would be "no ternary whose false-branch is a prop and true-branch is a
template literal", which false-positives across the codebase on legitimate defaulting. Recorded as prose
in `docs/MECHANICAL_GATES.md` instead of shipping a gate that blocks unrelated commits.
