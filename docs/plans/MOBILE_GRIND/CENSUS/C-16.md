## Why one item is a defect

`Home › Homes for sale` on `/homes-for-sale` renders exactly one link — to Home — which the logo
directly above already provides, plus the name of the page the reader is standing on. Zero navigational
information, ~200 device px, about 11% of a 375×812 viewport, on the site's highest-traffic page.

## Fix

Removed the crumb, with the gate's `// @no-breadcrumb` opt-out in the file header **and** an `EXEMPT`
entry in `check-breadcrumb.mjs`, so it is recorded as an intentional exception rather than drift.

**The BreadcrumbList JSON-LD went with it, deliberately.** It is emitted by the visible component, and a
two-item `Home > self` trail cannot earn a breadcrumb rich result — Google needs a real hierarchy. The
deep trails that can earn one (`/homes-for-sale/<city>`, listing detail) still emit theirs, untouched.
