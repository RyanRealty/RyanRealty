## 2. A user-facing page claiming methodology v4

`app/lp/bend/page.tsx:942` rendered `{kpis?.methodology_version ?? 'v4-2026-05-15'}`.

CLAUDE.md §7 is explicit: the v4 definition is registered in `cache_methodology_definitions`, but **no
live cache row carries it** — every served row is stamped `v3-2026-05-07`. "State `v3-2026-05-07` — that
is the stamp on the row — and never claim v4 for a served figure."

The fallback fired exactly when the row's own stamp was missing, i.e. precisely when the page had no
grounds to claim anything. **Fixed** to `v3-2026-05-07`.
