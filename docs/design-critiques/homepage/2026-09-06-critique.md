# Homepage — Ryan Realty (ryan-realty.com)
Date: 2026-09-06
Reviewed from: live URL screenshots (hero.png, mid.png)
Who: buyers (and sellers) looking at Central Oregon / Bend inventory
Job: find homes or understand the local market enough to start searching

## Verdict
The hero search does the right job, but the header stacks too many competing ways in, and the map legend leans on color alone.

## Fix first
1. **Header: full nav + hamburger + utilities fight the search.** Top bar shows Homes / Places / Market / Sell / About (all with chevrons), plus mic, phone, Saved, and Menu. Cost: a first-time buyer’s eye splits before they commit to “City, community, or address.” Fix: keep logo, one primary path into search/browse, phone, and Saved; park secondary links under a single Menu (or drop Menu on desktop when the full nav is already visible).
2. **Search field relies on placeholder as the only label.** Placeholder: “City, community, or address.” Cost: once they type, the hint disappears; screen readers and zoom users lose the field’s purpose. Fix: persistent visible label above or beside the field (e.g. “Search by city, community, or address”).
3. **Map status uses color as the only carrier.** “3,293 for sale” (dark dot) vs “903 pending” (light dot), plus FEWER/MORE SALES grayscale blocks. Cost: greyscale or low-vision users cannot tell status or intensity apart. Fix: pair each status with an icon or text pattern (not only fill), and add numeric or patterned steps on the sales legend.

## Worth fixing
- **Mic icon has no visible name.** Icon-only control next to the phone. Give it an accessible name and a tooltip (“Voice search”) or drop it if usage is low.
- **Hero headline is the brand, not the job.** “Ryan Realty, Bend” under “CENTRAL OREGON” looks premium but does not say what to do. Keep the photo; add a short job line above the search (e.g. “Find homes in Central Oregon”) so Search is framed.
- **All seven property types start checked.** House through Commercial all on, price “Up to any price.” Cost: filters look active but change nothing until the user unchecks—easy to miss. Default to the types most buyers want (House / Condo / Townhouse) or show a clear “All types” chip instead of seven checked boxes.
- **Sticky nav repeats the same density on the map section.** Same overload follows them down the page. Same fix as #1.

## Minor
- Phone number `541.703.3095` in the bar is useful; confirm tap target is large enough on mobile.
- Location chips (Sunriver 145, etc.) are strong—keep; just don’t bury them under the long filter stack.

## Working well
- Wide search + dark Search button is an obvious primary action on the hero.
- Aerial hero photography sells Bend immediately.
- “Every listing on the map” with live for-sale / pending counts is a clear second beat.
- Serif headlines + sans UI type read established without clutter in the map panel.

## Could not judge
- Exact contrast ratios (estimated from the shot; no color picker on the live CSS).
- Focus order, keyboard traps, and screen-reader names on the map and mic.
- Mobile / narrow breakpoints (desktop capture only).
- Empty, loading, and zero-result states for search and the map.
