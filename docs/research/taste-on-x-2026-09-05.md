## The stack (not a mood)

Taste on X in 2025–2026 is four layers:

1. A short anti-slop skill (Anthropic frontend-design, Hallmark, Taste Skill).
2. A pixel loop (Playwright screenshots, score, iterate).
3. A **second** agent that grades the first (self-praise is the named failure).
4. CSS/DOM checks that **fail the ship** when prose is ignored.

Adjective-heavy markdown is treated as skippable. What sticks: a named target, tokens the model cannot invent, screenshots (or computed styles), a pre-flight that is not optional.

## What they say actually works

[Vercel design.md](https://vercel.com/blog/how-our-agents-build-on-brand-pages-with-design-md): one public prompt failed. Working system is **judgment file + CSS vocabulary agents cannot invent + eval harness** that turns screenshot reviews into **deterministic checks**. Six pages: 91 named failures without design.md, 39 with. Every page still had at least one ship-blocker. If a complaint count does not fall after a prose rule, add a check, not another paragraph.

[Emil Kowalski](https://emilkowal.ski/ui/agents-with-taste): package taste as strict per-aspect rules (easing, duration, `scale(0.95)` not `scale(0)`), not “make it premium.”

Screenshots + copied CSS beat screenshot-only. Review the live page, not the JSX.

## Mechanical slop (this is our leftover HUD)

Nobody on X says “KPI tiles.” They fail the same object under other names:

- Anthropic: “big number with a small label, supporting stats, and a gradient accent”
- [Impeccable](https://impeccable.style/docs/critique): “Hero metric layout”
- [Adrian Krebs](https://www.adriankrebs.ch/blog/design-slop/): “Stat banner rows” — computed-style walk, **no LLM**. 4+ tells = high slop.

That is Bend’s `679` / `$950,000` / `3.9` / `23` strip. A JSON score of 86 cannot outvote it.
