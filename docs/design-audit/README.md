> **2026-07-11 addendum: [Search System Audit](search-audit-2026-07-11.md)** — ground-up review of the property-search experience (filters, save-search, boundary drawing, radius/POI search, counts, mailed alerts, mobile). 3 P0s found (More-filters crash — fixed in-session; RPC timeout rendering as a false "no homes match"; amenity filters silently ignored in the default view), save-search missing its front door, and a 6-step rebuild plan. Evidence in [`assets/search2/`](assets/search2/).

**Date:** 2026-07-07 · **Auditor:** Claude (senior-design-lead lens, 19-agent audit + evidence verification) · **Build:** local `next dev` off `main` @ `62ba1c7a`

**The question this audit answers:** can a normal Bend buyer or seller land on ryan-realty.com, understand what it is, trust it enough to hand over contact info, and finish the core action (find a home and ask about it / request a home valuation) without help — measured against the Zillow-class bar consumers arrive with. Not "does it look nice."

**Verdict:** the bones are genuinely strong — the brand system is distinctive, the plain-language search actually works ("3 bed under $800k in Bend" parses to real filters), the seller LP is a model conversion page, and licensing/trust signals are present where they matter. But the site was losing conversions to a small number of severe, mostly mechanical defects: invisible CTA text on the seller money path, a mortgage calculator defaulting ~2.8× under the honest payment, primary mobile nav links that were physically unreachable, and a family of "same stat, different number" data contradictions that undercut the brand's core promise of arithmetic honesty. **23 of the worst defects were fixed and browser-verified during the audit** (register marked accordingly); the remaining work is ranked below.

## The six themes that explain most of the register

1. **One hero template forced onto every intent.** The (beautiful) editorial hero ships with a buyer search bar, "Browse →" as the filled primary CTA, and a listings-count stat line — and it was dropped onto seller pages, the contact page, tools, and content hubs. Sellers were greeted with buyer search; the valuation page's own hero CTA linked to itself. The template needs per-page CTA intent, not more pages needing exceptions. *(Partially fixed: search bar removed from /contact + /sell/valuation; KbHero still hardcodes Browse/Sell CTAs — top recommendation.)*

2. **Same stat, different number.** Identical-looking "N ACTIVE · $X median" ledgers are fed by different sources on different pages (`geo_snapshot_mv` vs `market_pulse_live` vs live tile counts): Bend is 788 on the homepage and 500 on /housing-market; Sisters 110 vs 41; Pronghorn's median showed $194K because land lots contaminated an SFR ledger. For a brand whose positioning is "real numbers," this is the most strategically corrosive class in the register. One canonical source per metric, one label per scope. *(Scope mislabels on /sell and the neighborhood activity feed fixed; source unification is the #1 open recommendation.)*

3. **The register seam lands mid-task.** The site intentionally runs two chromes — editorial (home, listings, content) and portal (search results). The seam falls exactly on search → listing, the highest-frequency transition in the buy path: nav vocabulary changes, Sign in and "Get listing alerts" vanish, breadcrumbs disappear. Keep both skins, but carry a continuity strap (account affordance + aligned nav labels) across the seam.

4. **Un-layered CSS silently beats Tailwind utilities.** `kb.css` sits outside the cascade layers, so its `a { color:inherit }` outranked every `.text-white` on every CTA link inside editorial pages — filled navy buttons rendered navy-on-navy at the exact moments pages ask users to convert. Same class of bug: the luxury page imported nav components without their stylesheet and rendered raw. *(Both fixed; the pattern is worth a lint rule — see recommendations.)*

5. **Media states paint black.** Featured-home cards autoplay MLS tour videos on scroll and show a black rectangle while buffering (or forever, when autoplay is blocked); Zillow-hosted 3D tours render a competitor logo plus a bot-wall CAPTCHA inside the listing page; the canonical listing route has no loading skeleton, so the search → listing tap dead-clicks for 1–3s.

6. **What's already excellent** — worth saying out loud: the natural-language search is a real differentiator and it works; /lp/sell-your-home is exactly what a seller conversion page should be (focused chrome, specific proof, one CTA); the footer's license line, TCPA-careful consent copy, and dotted-phone consistency read as a professional operation; the a11y baseline (labeled controls, skip link, aria-labels on cards) is well above average.

## Bigger recommendations (not attempted — need design/product decisions)

1. **Unify the market-stat pipeline** (theme 2): one DAL source per metric, one scope label convention, and a nightly gate that diffs the same geo across surfaces and fails on >1% disagreement — the same discipline §0 already mandates for videos, applied to the site.
2. **Give KbHero intent variants**: per-page CTA row (label + href + which is primary) and an address-capture variant for seller surfaces, so the seller money pages lead with "Get my home value" instead of Browse.
3. **In-page tour scheduling** on listing detail (property card + time slots + question variant), replacing the /contact hop.
4. **Bridge the register seam**: shared account/alerts affordances and aligned nav vocabulary between the portal and editorial chromes.
5. **Featured-homes curation**: price-desc ($5.9M–$11.9M) doesn't serve a $740K-median audience; curate a mix per town, dedupe by street, show acreage where it explains price.
6. **Media loading discipline**: photo stays visible until video `canplay`; no direct iframes from hosts that bot-wall (Zillow); skeletons on every rewrite target.
7. **Signup flow truthfulness** (P1): `ok:true` without a session silently dumps new users, signed out, on the homepage — return a `needsConfirmation` state and render "check your email."
8. **Cascade-layer lint**: a gate that flags un-layered element selectors in imported CSS files (the class of bug behind #1) would have caught this at commit time.

### P0 + P1 — every finding in detail

#### P0 · Sell path — /sell, valuation, contact, LP · `/sell + /sell/valuation` (both) — **FIXED in this audit**

**Hurts:** conversion, understanding · **Dimension:** component-consistency · **Quick win:** yes

Every filled valuation CTA on the seller money path renders as a blank rectangle with invisible text: the 3% fee callout button, the 'Get my free valuation' button, the navy CTA bar's 'Get a home valuation', and /sell/valuation's 'Our selling plan'. Verified live: computed color is navy-on-navy (rgb(16,39,66) on #102742) or white-on-white. A seller sees empty navy/white boxes at the exact moments the page asks them to convert.

**Fix:** components/site/kb/kb.css line 44: `.kb-root a{color:inherit}` has higher specificity (0,1,1) than Tailwind's `.text-white`/`.text-primary` (0,1,0), so it clobbers the text color on every CTAButton and shadcn `<Button asChild><Link>` inside kb-root pages. Change it to `:where(.kb-root a){color:inherit;text-decoration:none}` so utility classes on links win again, then spot-check kb pages for links that relied on the override.

**Evidence:** sell-desktop-03.png (blank navy button in 3% callout), sell-desktop-07.png (blank navy button next to 'Or call 541.703.3095'), sell-desktop-08.png (blank white button next to 'Talk to a broker'), sell-valuation-fixed-desktop-03.png (blank navy button next to 'Contact us to sell'); source components/site/kb/kb.css:44, components/site/primitives/CTA.tsx, app/sell/valuation/page.tsx:155; confirmed via live computed styles on localhost:3000/sell and /sell/valuation

<sub>Verifier: Verified in sell-desktop-03/07/08, sell-valuation-fixed-desktop-03: every filled CTA on the seller path is a blank navy/white box. Source confirmed (kb.css anchor reset; CTA.tsx uses single-class text-white; 'Our selling plan' at app/sell/valuation/page.tsx:155).
