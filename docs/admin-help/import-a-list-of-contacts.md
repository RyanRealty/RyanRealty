When you have a spreadsheet of past clients or a purchased list, import it instead of typing each person in.

## Steps

1. Go to **CRM, then Contacts, then Import**, and start a new import.
2. Upload your spreadsheet.
3. Map your columns. The importer reads the headers and lets you line each one up with a CRM field: first name, last name, email, phone, tags, source.
4. Preview the mapped rows to confirm the data landed where you expect.
5. Run it. Rows import in the background, so a large file never ties up your screen.

## Good to know

- Give the whole batch a **source** so you can report on where it came from later.
- Import uses the same duplicate check as adding one contact. A row whose email or phone already matches someone updates that person instead of creating a duplicate.
- You can watch progress on the import page and see any rows that could not be read, so nothing fails silently.

## After the import

- Tag the group so you can find and work them together. See the article on grouping your leads.
- Put shoppers on a listing alert, or subscribe past clients to a market report for their area.
